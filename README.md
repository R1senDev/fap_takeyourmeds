# Take your Meds

**Medication tracker app for Flipper Zero.**

![Anny.200 Splash screen shot](https://i.imgur.com/Itenq7o.png)
![Main Menu](https://i.imgur.com/LT4Zjhp.png)

> App is in WIP state and being actively worked on.

## Features

**On the roadmap:**
- Add up to 16 different medicines;
- Set any target amount of intakes per day for each medicine;
- Review your daily streak stats;
- Get achievements!

Also, I'd be glad to hear your suggestions about any additional features that I could implement!
